# 对话交接摘要

本项目长期维护的是 FreeKill 国战扩展。自定义包名称固定为 `fengsui`（烽燧）和 `tianzong`（天纵），不要误写成“风水”。

## 已确定的仓库关系

- `jozily/fengsui`：烽燧扩展完整仓库。
- `jozily/tianzong`：天纵扩展完整仓库。
- `jozily/backup`：归档仓库，包含两个扩展、无名杀扩展备份、恢复文档、`packages.db` 和校验清单。

## 重要运行约定

- 官方扩展从官方 Gitee 导入，不从本归档覆盖。
- 自定义扩展放在 FreeKill `packages/` 下，并在 `packages.db` 注册。
- 修改后必须检查客户端实际加载日志、扩展注册数量、资源路径和 9527 端口。
- 不能只根据 Git 状态判断部署成功；必须核对服务器工作树、数据库 URL/版本、容器日志和端口。
- 牌名选择组件、移动端按钮、技能触发时机、标记可见性和资源尺寸都需要实际游戏验证，不能只做 Lua 语法检查。

## 主要历史问题

- 曾出现牌名选择只默认第一项、确定按钮灰色、目标数据沿用上一张牌的问题；修复时要同时核对客户端交互和服务端收到的牌名。
- 曾出现 MD5/no match for id、formation/addcompanionrule、服务器远程包路径不一致等部署问题；更新后必须重新生成并核对客户端清单。
- `fengsui` 和 `tianzong` 的图片、语音、衍生标记、QML 都属于扩展完整内容，迁移时不能只复制 Lua。
- 官方包和自定义包必须分开维护，官方更新不应覆盖自定义包。

## 新 Codex 接手方式

先阅读本目录下的 `项目交接.md`、`重启恢复提示词.md`、`服务器搭建方法.md`、本文件和 `manifests/SHA256SUMS.txt`；再检查三个 GitHub 仓库的最新提交，最后按恢复文档部署和验证。
