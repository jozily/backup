# 国战1 服务器重启与恢复提示词

先阅读 `handover/项目交接.md`、`handover/服务器恢复.md` 和 `manifests/SHA256SUMS.txt`。

恢复顺序：将 `freekill/fengsui`、`freekill/tianzong` 放回 FreeKill 的 `packages/`；将 `noname/extension` 放回无名杀 `resources/app/extension`；恢复服务器数据库、Docker 配置和 RSA 文件；核对仓库 HEAD 与 `packages.db` 的 hash；启动 `freekill`，确认扩展加载和 9527 端口；客户端先单机验证，再连接服务器。

不要覆盖官方核心包。修改先提交到对应仓库，再部署并更新 `packages.db`。

## 当前服务器结构

自定义扩展只有两个：

- `packages/fengsui` -> `https://github.com/jozily/fengsui.git`
- `packages/tianzong` -> `https://github.com/jozily/tianzong.git`

它们的完整归档位于本仓库的 `freekill/fengsui` 和 `freekill/tianzong`。

除上述两个扩展外，当前服务器使用的官方扩展目录为：

`freekill-core`、`gamemode`、`hegemony`、`jsrg`、`mini`、`mobile`、`mougong`、`offline_new`、`ol`、`overseas`、`shzl`、`sp`、`standard_ex`、`sxrm`、`tenyear`、`utility`、`yj`。

官方扩展不需要从本归档复制。重新搭建官方 FreeKill 后，将这些目录从官方 Gitee 源导入到：

`<FreeKill根目录>/packages/`

核心目录为：

`<FreeKill根目录>/packages/freekill-core/`

导入官方扩展时保持官方仓库的目录名和版本，不要用 `backup` 中的自定义目录覆盖它们。然后再复制 `freekill/fengsui` 和 `freekill/tianzong`，设置各自 GitHub remote，最后更新 `packages.db`。

## 最小恢复步骤

1. 安装与服务器相同版本的官方 FreeKill。
2. 从官方 Gitee 导入上面列出的官方扩展到 `packages/`。
3. 从本仓库复制 `freekill/fengsui`、`freekill/tianzong` 到 `packages/`。
4. 启动一次并检查日志中的扩展加载数量和错误。
5. 更新 `packages.db` 中两个自定义扩展的 URL 为 GitHub 地址。
6. 重启服务，确认 9527 端口、客户端连接和武将/卡牌资源加载正常。
