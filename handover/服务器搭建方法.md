# FreeKill 服务器搭建方法

## 目录

- 服务器根目录：`/docker/新月杀`
- 扩展目录：`/docker/新月杀/packages`
- 包数据库：`/docker/新月杀/packages/packages.db`
- Docker 服务：`freekill`（部分环境使用 `freekill-static`）
- 游戏端口：`9527`

## 搭建顺序

1. 安装 Docker、Git 和与原服务器相同版本的 FreeKill 官方服务端。
2. 将官方 FreeKill 源码放入 `/docker/新月杀`。
3. 从官方 Gitee 导入官方扩展，保持原目录名：`freekill-core`、`gamemode`、`hegemony`、`jsrg`、`mini`、`mobile`、`mougong`、`offline_new`、`ol`、`overseas`、`shzl`、`sp`、`standard_ex`、`sxrm`、`tenyear`、`utility`、`yj`。
4. 从 `jozily/backup` 复制 `freekill/fengsui` 和 `freekill/tianzong` 到 `packages/`，或分别从 `jozily/fengsui`、`jozily/tianzong` 克隆。
5. 在 `packages.db` 中登记两个自定义包，并使用 GitHub URL。
6. 启动 Docker 服务，查看日志确认包加载成功。
7. 检查 9527 端口，再用客户端进行单机和联网测试。

## 更新与重启

在扩展目录执行 `git pull` 或由包管理器更新；更新后检查工作树和提交号，再重启容器：

```bash
docker restart freekill
docker ps
ss -ltnp | grep 9527
```

不要把 `backup` 根目录直接当成扩展仓库；自定义包必须使用 `freekill/fengsui`、`freekill/tianzong` 子目录或两个独立 GitHub 仓库。
